# SEO metrics

Review Search Console impressions, clicks, queries and pages by cluster each week. Watch for two pages competing for the same intent, crawl or indexing errors, and changes in coverage. At weeks 4, 8 and 12, use impressions to reprioritize the content backlog.

Use Umami for page views, `clicked_open_studio`, `opened_studio` and `kept_take` in the SEO-to-creator funnel described in [analytics.md](analytics.md). Segment by landing page and device class. The Studio events become available as their milestones ship. Treat local device IDs as directional across profiles and devices.
