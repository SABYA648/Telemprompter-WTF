# Studio device QA before launch

Record the browser version, device model, result and any saved sample file for each run. The owner performs this checklist before merging the launch PR.

## Devices

- [ ] iPhone Safari on iOS 17, in Safari and as a Home Screen app
- [ ] iPhone Safari on iOS 18, in Safari and as a Home Screen app
- [ ] iPhone Safari on iOS 26, in Safari and as a Home Screen app
- [ ] Android Chrome on a mid-range phone
- [ ] macOS Safari and Chrome
- [ ] Windows Chrome and Edge
- [ ] Firefox desktop

## Recording and export

- [ ] Preview is upright in portrait and both landscape rotations.
- [ ] Record a short take, keep it, reload, play it, save it and play the saved file in Photos or Gallery.
- [ ] Upload the saved file to Instagram as a Reel and to YouTube Shorts.
- [ ] Front camera preview mirrors naturally; the saved file has the expected orientation. Flip cameras.
- [ ] Test an external microphone, the mic check, room noise and clipping indicators.
- [ ] Select 4K where the device offers it; verify resolution and frame rate of the saved file.
- [ ] Switch apps during recording; confirm interruption is explained and the take is recoverable.
- [ ] Kill a tab while recording, reopen Studio and recover the take.
- [ ] Confirm the screen stays awake while recording where wake lock is available.
- [ ] Test WPM scrolling, pause markers, safe zones, clicker keys and the desktop editor.

## App, privacy and habit

- [ ] Install Studio and verify icon, shortcuts, standalone display and offline opening.
- [ ] In airplane mode, open Studio and a never-visited guide; confirm the offline page.
- [ ] Export and import a transfer code; verify scripts and settings arrive and takes do not.
- [ ] Add the .ics daily reminder; verify local time, daily repeat, alarm and calendar link behavior.
- [ ] Keep a take and verify the streak badge; revisit on the next local day.
- [ ] Verify the homepage CTA is visible at 390x844, classic editor still works, and returning Studio users see the mobile bar.
- [ ] Check keyboard navigation, visible focus, screen reader labels and reduced motion.
