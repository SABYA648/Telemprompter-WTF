# Changelog

All notable changes to this project are documented here.

## [2.0.0] - Unreleased

### Added

- Studio: local script library, lens-side camera recording, take review and export, pro camera and microphone controls, offline Home Screen app, share target, transfer codes, streak counter and daily calendar reminder.
- Creator-focused homepage, Studio navigation and returning-visitor entry point.
- Self-hosted Umami product analytics with typed, content-free events.

### Changed

- The classic presenter uses manual scrolling. Voice auto-follow and its local speech model were removed.
- Homepage and public pages now describe Studio and the classic presenter.
